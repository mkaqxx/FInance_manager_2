# Публичный контракт ядра (Public API)

* **Что здесь будет:** Заголовочные файлы фасада `FinanceCoreBridge.hpp` и структур данных `FinanceCoreTypes.hpp`.
* **Для чего:** Это единственный каталог ядра, который видят внешние приложения (Windows-хост и iOS-компаньон).
* **Архитектурное правило:** Строго C++20 `noexcept`, без исключений и сложных C++23 типов в публичных сигнатурах — для полной совместимости со Swift 6 C++ Interop на iOS.
