# Бизнес-логика и финансовая математика (Domain Logic)

* **Что здесь будет:**
  * `BudgetMath.hpp / .cpp` — формула живого безопасного дневного лимита ($L_{\text{today}}$) с адаптивным сжатием мягких целей ($\alpha$).
  * `MoneyRouter.hpp / .cpp` — автоматический маршрутизатор входящих доходов (FIXED и PERCENT правила).
  * `Reconciliation.hpp / .cpp` — сверка по фактическому остатку карты (создание корректирующей записи `RECONCILED`).
  * `FxConverter.hpp / .cpp` — 128-битный точный пересчет валют по курсам НБ РБ.
* **Для чего:** Чистая математика без внешних зависимостей и без прямого доступа к SQL.
