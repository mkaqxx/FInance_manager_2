# Системные утилиты (Utilities)

* **Что здесь будет:**
  * `UuidV7.hpp / .cpp` — генератор монотонно возрастающих идентификаторов UUIDv7 (кластеризация по времени).
  * `CryptoHash.hpp / .cpp` — SHA-256 хеширование строк выписок для дедупликации.
  * `Int128Math.hpp` — макросы и платформенные интринсики 128-битной арифметики (`_mul128` под MSVC, `__int128` под Clang).
* **Для чего:** Базовый фундамент ядра для уникальности ключей и математической точности без IEEE 754.
