# Парсинг выписок и дедупликация (Parsers & Deduplication)

* **Что здесь будет:**
  * `TextEncoding.hpp / .cpp` — быстрый декодер Windows-1251 -> UTF-8.
  * `BankCsvImporter.hpp / .cpp` — адаптеры форматов выписок банков РБ (Приорбанк, Беларусбанк, МТБанк, Альфа-Банк).
  * `DeduplicationEngine.hpp / .cpp` — 3-проходная дедупликация (SHA-256 хеш строки, нечеткая склейка Джаро — Винклера $\ge 0.72$ за $\pm 72$ ч, автокатегоризация).
* **Для чего:** Автоматический разбор банковских файлов и склеивание операций без дубликатов.
