# Служебные скрипты автоматизации (Automation Scripts)

* **Что здесь находится:**
  * `build_xcframework.sh` — кросс-компиляция C++ ядра в `FinanceCore.xcframework` для iOS.
  * `generate_test_data.py` — генератор реалистичных выписок банков РБ в кодировках CP1251 и UTF-8.
  * `sample_statements/` — каталог сгенерированных тестовых CSV-выписок (Приорбанк, Беларусбанк, МТБанк, Альфа-Банк).
  * `bundle_ui.py` — сборка и копирование ассетов `web-ui/` для десктопного приложения Windows.
  * `format_code.ps1` / `format_code.bat` — автоформатирование C++ кода ядра через `clang-format`.
* **Для чего:** Автоматизация рутинных процессов разработчика и CI/CD.
