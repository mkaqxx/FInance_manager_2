# iOS Companion (Мобильное приложение)

* **Что здесь будет:**
  * `Sources/App/` — нативное SwiftUI приложение (экран лимита и бюджета, связка ключей `KeychainHelper.swift`, обработка `finance://`).
  * `Sources/Widgets/` — виджеты экрана блокировки и кнопки действия WidgetKit / AppIntents.
  * `Resources/` — манифесты `Info.plist` и entitlements.
  * `project.yml` — спецификация для генератора XcodeGen.
* **Для чего:** Быстрый ввод расхода на кассе, отображение безопасного дневного лимита и локальная P2P-синхронизация по домашней сети.
