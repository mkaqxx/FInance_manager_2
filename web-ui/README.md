# Веб-интерфейс десктопа (SPA Frontend)

* **Что здесь будет:**
  * `index.html` — главная разметка одностраничного приложения.
  * `css/` — стили и темы интерфейса.
  * `js/` — клиентская логика дашборда (шкала дней до зарплаты, радар $L_{\text{today}}$, конверты, счета, QR-код привязки).
* **Для чего:** Легковесный графический интерфейс, отображаемый внутри Edge WebView2. Общается с C++ ядром через `window.chrome.webview.postMessage`.
